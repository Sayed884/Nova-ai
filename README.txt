NOVA AI — Add-to-Home-Screen package

This is a Progressive Web App (PWA) package, not a Play Store app.

IMPORTANT:
- Android Chrome requires the files to be served from an HTTPS website (or localhost).
- Opening index.html directly as a file will let you preview the site, but install/offline-app features will not work.
- Upload the CONTENTS of this folder to any static HTTPS host.
- Then open the HTTPS address in Chrome on your Android phone.
- Tap ⋮ (three dots) > Add to Home screen or Install app.
- Confirm. NOVA AI will get an icon and open in its own app-like window.

Files:
- index.html: NOVA AI website
- manifest.webmanifest: app name, icon and standalone display settings
- sw.js: offline cache
- icons/: home-screen icons

The chat is still a prototype; real AI services need to be connected separately.
